# Foram Patel — Portfolio

Static portfolio with original local images, videos, resume, fonts, design and animations.
The root index.html includes CSS and JavaScript. Keep assets/ alongside it.
GitHub Pages is deployed automatically by .github/workflows/static.yml on pushes to main.

To update: replace index.html and changed assets, commit, then push using GitHub Desktop.
No build step or dependencies are needed. External Instagram/profile/product links require the internet.
